# Identidad visual de SIGLO

Esta carpeta contiene los recursos visuales intercambiables del aplicativo.

## Archivos principales

- `logo-siglo.png`: logo completo de SIGLO. Si existe, el Login lo usa automáticamente.
- `logo-siglo.svg`: logo de respaldo temporal. No es necesario modificarlo si se usa el PNG.
- `icono-siglo.png`: isotipo de SIGLO para futuras pantallas y navegación.
- `icono-siglo.svg`: isotipo de respaldo temporal.
- `login-wallpaper.jpg`: imagen principal del fondo del Login. Si existe, reemplaza visualmente el wallpaper temporal.
- `login-wallpaper.svg`: wallpaper de respaldo temporal.

## Recomendaciones

### logo-siglo.png
- PNG con fondo transparente.
- Preferible formato horizontal.
- Ancho recomendado: 1200 px o más.

### icono-siglo.png
- PNG cuadrado con fondo transparente.
- Recomendado: 512 x 512 px o superior.

### login-wallpaper.jpg
- JPG horizontal.
- Recomendado: 1920 x 1080 px o superior.
- Evitar texto importante muy cerca de los bordes.

Para reemplazar una imagen, conservar exactamente el nombre indicado. El código no necesita modificarse.
